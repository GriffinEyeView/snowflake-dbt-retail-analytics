# Retail Analytics Data Warehouse

An end-to-end data engineering portfolio project using Snowflake, dbt, SQL, and Python.

## Objectives
- Load retail sales data into Snowflake.
- Transform raw data into analytics-ready models with dbt.
- Add data quality tests and model documentation.
- Track development and reproducible setup with Git.

## Architecture
CSV source data -> Snowflake raw tables -> dbt staging models -> analytics marts.

## Status
In development. Implementation and validation results will be documented as the pipeline is built.

## Technology Stack
- Snowflake
- dbt Core
- SQL
- Python
- Git and GitHub
